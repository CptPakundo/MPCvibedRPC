    What this shows

    The flow from a wrong card. Click Wrong title or cover? under the preview, type in the box (results update as you type, after a short pause), pick a row, then Use this.

    Step 1: Fix this match

    • The first line says where the title came from (the file name only, never its folder) and what it was read as. That answers "what am I fixing?".
    • The box starts with the read title; the list starts with the closest results the lookup already saw, so often no typing is needed.
    • Each row: cover, name, year, movie or show, and the catalog. The current match says "Now".
    • The last row keeps the old behaviour: search under the typed name, without pinning an entry.
    • Only catalogs switched on under Privacy are asked; with all off, the box says so and only the last row is offered.
    • "For every file read as Sample Show": the scope in one line. All episodes of the show follow.

    Step 2: Fixed

    • "Use this" saved it (settings save as they change); Undo removes it.
    • Cover: the entry's own, another catalog's cover of the same title, or an image address (today's "Pin a cover image").
    • "Episodes don't line up?" is a later step (season and episode offset), shown folded.
    • "Tell the project about this" opens the copy-and-post dialog (second mockup). Nothing is sent by the program.
