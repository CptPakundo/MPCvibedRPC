---
name: new-host
description: Rule for any new outside address (a service, a link, an image) that MPCvibedRPC's code or page names - core.Hosts and SECURITY.md, checked by TestEveryHostIsListed.
---
**New outside address:** any host the code names (a service, a link, an image) goes in `core.Hosts` (or
`core.Sources`) and in `SECURITY.md` > Where it connects; `TestEveryHostIsListed` scans the code and the page and
fails otherwise.
